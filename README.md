# Frozen Trail: полевой гайд

Фанатский сайт-гайд по обновлению **Frozen Trail (2.0)** для ARC Raiders: Фрегат с 3D-картой и чек-листом рейда, Император и Redirection, амплификация оружия и ресурсы, Outpost и Research Station, Pendola Pass, новые ARC, оружие, гаджеты, навыки и прочие изменения. Данные собраны 9 октября 2026, ссылки на источники стоят внизу каждого раздела.

Сайт статический: HTML, CSS и JavaScript без сборки и без внешних библиотек (3D-движок свой, лежит в `js/ft3d.js`). Из интернета подгружаются шрифты Google Fonts и превью роликов YouTube; сам плеер YouTube загружается, только когда нажимаешь на видео.

## Как открыть у себя

Достаточно дважды кликнуть `index.html`. Всё работает и без сервера.

## Как выложить на GitHub Pages

### Вариант без командной строки

1. Зайди на [github.com/new](https://github.com/new), назови репозиторий, например `frozen-trail-guide`, сделай его **Public** и нажми **Create repository**.
2. На странице репозитория нажми **uploading an existing file** (или **Add file → Upload files**).
3. Перетащи в окно **всё содержимое** этой папки: `index.html`, `README.md`, `.nojekyll` и папки `css`, `js`, `assets`. Нажми **Commit changes**.
4. Открой **Settings → Pages**. В блоке **Build and deployment** выбери **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**, нажми **Save**.
5. Через минуту-две сайт будет доступен по адресу `https://<твой-ник>.github.io/frozen-trail-guide/`. Эту ссылку и кидай друзьям.

### Вариант через git

```bash
cd путь/к/папке/ArcRaiders
git init
git add .
git commit -m "Frozen Trail guide"
git branch -M main
git remote add origin https://github.com/<твой-ник>/frozen-trail-guide.git
git push -u origin main
```

Дальше пункт 4 из варианта выше. Каждый следующий `git push` обновляет сайт автоматически.

## Как обновлять

Все данные лежат отдельно от вёрстки, в `js/data/`:

| Файл | Что внутри |
|---|---|
| `frigate.js` | Точки Фрегата: шаги маршрута, цели, лут, опасности и тексты к ним |
| `frigate3d.js` | Где эти точки висят на 3D-модели и куда смотрит камера на каждом шаге |
| `amplified.js` | 15 амплифицируемых пушек, их ветки и исследования уровня 4 |
| `resources.js` | Таблица «Ресурсы: что где брать» |
| `research.js` | Чертежи Research Station по уровням |
| `pendola.js` | Места Pendola Pass, районы и метки для карты |
| `videos.js` | Ролики с YouTube: Фрегат, Император, обзор обновления |
| `sources.js` | Все ссылки на источники |

Пометка «уточняется» на сайте означает, что данных пока нет или источники расходятся. Когда в игре что-то выяснится, правь нужный файл и заливай заново.

## Карта Pendola Pass

1. Сделай в игре скриншот карты Pendola Pass.
2. Положи его в `assets/maps/` с именем `pendola-pass.jpg` (подойдут также `.png` и `.webp`).
3. Открой сайт: в разделе Pendola Pass появится карта с зумом и перетаскиванием.
4. Включи **Режим разметки** и кликай по карте, чтобы ставить метки. Они сохраняются в твоём браузере.
5. Нажми **Экспорт меток**, скопируй JSON и вставь его вместо `markers: []` в `js/data/pendola.js`. После заливки метки увидят все.

## Видео из игры

Ролики стоят в трёх местах: на вкладке **«Видео из игры»** у карты Фрегата, в разделе «Император» и в начале страницы. Список лежит в `js/data/videos.js`. Чтобы добавить ролик, скопируй строку в нужной группе и поменяй `id` на код из ссылки: в `https://www.youtube.com/watch?v=fw-dXQoGVDc` код — `fw-dXQoGVDc`.

Если открыть сайт двойным кликом по `index.html`, YouTube не даёт встроить плеер в страницу с диска. Поэтому ролик в таком случае откроется на сайте YouTube. На GitHub Pages видео играет прямо на странице.

## Скриншоты из игры

К каждой точке Фрегата можно добавить свой скриншот. Положи картинку в `assets/frigate/` с именем по коду точки: `r5.jpg` для трёх рычагов, `r9.jpg` для жёлтого вентиля и так далее (подойдут также `.png` и `.webp`). Для одной точки можно положить до трёх картинок: `r5.jpg`, `r5-2.jpg`, `r5-3.jpg`. Сайт сам найдёт их и покажет в карточке точки. Все коды перечислены в `assets/frigate/README.txt`.

## 3D-модель

Модель Фрегата условная: это не игровая модель, а тактическая схема в стиле голограммы. По ней видно, в каком порядке идти и где что находится. Как всё выглядит на самом деле, смотри во вкладке «Видео из игры» и на скриншотах. Цвета:

- красный пунктир с номерами — маршрут, точечная линия — путь отхода;
- жёлто-оранжевый — что ломать или простреливать (Гидры, ядра, жёлтые узлы и вентиль);
- голубой — лут;
- красный — опасности (турели на днище);
- белый (в светлой теме чёрный) — то, с чем нужно взаимодействовать: рычаги, лифт, боковые панели.

Если устройство не поддерживает WebGL, сайт сам переключится на обычную схему (вкладка «Схема»).
