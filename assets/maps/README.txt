Сюда кладётся скриншот карты Pendola Pass из игры.

Имя файла: pendola-pass.jpg (или pendola-pass.png / pendola-pass.webp).
После этого на сайте в разделе Pendola Pass появится интерактивная карта:
- колесо мыши или +/− меняют масштаб, карту можно таскать;
- «Режим разметки» + клик по карте = новая метка (хранится в браузере);
- «Экспорт меток» даёт JSON, который нужно вставить в js/data/pendola.js вместо markers: [],
  чтобы метки увидели все, кто открывает сайт.
